Zasady używania

MFDesk · aktualizacja: 14 września 2026 r.

Tylko za zgodą właściciela

Używaj MFDesk wyłącznie na komputerach należących do Ciebie lub tych, do których masz wyraźne upoważnienie. Dostęp nienadzorowany nie zastępuje zgody właściciela. Klucz MFDesk umożliwia sterowanie komputerem — traktuj go jak hasło i nie publikuj.

Wersja testowa do pobrania

MFDesk nie jest usługą komercyjną, produktem Google ani odmianą AnyDesk. Strona udostępnia instalator testowy Windows przez GitHub Releases. Od wydania 2.3.0-beta.1 dostępne są opcjonalne logowanie GitHub i synchronizacja w Cloudflare po zatwierdzeniu konta przez właściciela usługi. Projekt pozostaje w rozwoju, bez gwarancji dostępności i bez niezależnego audytu bezpieczeństwa. Nie należy używać go jako jedynej metody dostępu do systemów krytycznych. Zachowaj alternatywny dostęp oraz kopię potrzebnych danych.

Instalacja

Instalator wymaga uprawnień administratora. Dodaje usługę dostępu zdalnego MFDeskHost uruchamianą automatycznie jako LocalSystem, regułę zapory oraz skróty. Zamknięcie okna aplikacji nie zatrzymuje usługi. Nie zakładaj, że wersja testowa zapewni dostęp po blokadzie, wylogowaniu lub restarcie Windows. Instalator nie jest podpisany cyfrowo; Windows może ostrzegać przed nieznanym wydawcą. Nie wyłączaj ochrony systemu.

Koszty i usługi zewnętrzne

MFDesk nie pobiera abonamentu ani danych karty płatniczej. Usługa kont korzysta z planów Cloudflare Workers Free i D1 Free; nie włączono płatnego planu. Nadal mogą obowiązywać koszty Twojego internetu, własnych usług dodatkowych , jeśli samodzielnie je zamówisz. Usługi zewnętrzne mają własne limity i warunki, które mogą ulec zmianie.

Znane ograniczenia

Połączenie bez pośrednika TURN może nie działać w niektórych sieciach. W poprzednim wydaniu 2.2.0-beta.5 zweryfikowano obraz zablokowanego Windows i powrót po ręcznym odblokowaniu na tym samym połączeniu. Zdalne wpisywanie hasła lub PIN-u, UAC, Ctrl+Alt+Del oraz dostęp po restarcie nie są jeszcze zweryfikowane. Nie przeprowadzono pełnego testu na dwóch fizycznych komputerach w niezależnych sieciach. Android jest planowany. Synchronizacja nie unieważnia wcześniej skopiowanych kluczy zdalnego dostępu.

Dane i hasło sejfu

Bez konta ulubione pozostają lokalnie. Opcjonalne logowanie GitHub umożliwia synchronizację zgodnie z polityką prywatności; import lokalnych ulubionych wymaga osobnego wyboru. Własne hasło sejfu i wcześniej wygenerowany kod ratunkowy należy zachować w bezpiecznym miejscu. Kod umożliwia odblokowanie sejfu, nie resetuje hasła i obecnie nie można go unieważnić ani wymienić. MFDesk nie wysyła kodów e-mailem. GitHub może wymagać ponownej autoryzacji po cofnięciu zgody lub z przyczyn bezpieczeństwa.
