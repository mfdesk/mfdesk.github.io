Polityka prywatności

MFDesk · aktualizacja: 14 września 2026 r. · wydanie 2.3

MFDesk to prywatny projekt pulpitu zdalnego. Konto jest opcjonalne: można używać połączeń i ulubionych wyłącznie lokalnie. Wydanie 2.3 używa logowania GitHub i prywatnej usługi Cloudflare zamiast Google Drive i Apps Script.

1. Logowanie i zatwierdzanie kont

GitHub potwierdza publiczny, liczbowy identyfikator i login użytkownika. MFDesk nie prosi o prywatne repozytoria, prywatny adres e-mail, dokumenty ani hasło GitHub. Zakres offline_access pozwala odświeżać sesję. Nowe konto oczekuje na zatwierdzenie administratora; przed akceptacją nie może przechowywać ani odczytywać sejfu. Administrator jest przypisany do konkretnego identyfikatora, nie pierwszego rejestrującego się użytkownika.

Aplikacja przechowuje tokeny dostępu i odświeżania pod ochroną Windows DPAPI. Token dostępu jest przesyłany przez HTTPS do stałego adresu usługi MFDesk w Cloudflare i weryfikowany w GitHub przy każdej operacji. Token odświeżania trafia tylko do GitHub. Kod urządzenia służy jednorazowej autoryzacji w przeglądarce. MFDesk nie zapisuje tokenów w publicznych adresach URL ani celowo w dziennikach usługi.

2. Co znajduje się w sejfie

Sejf zawiera nazwy i identyfikatory komputerów, klucze dostępu MFDesk, czas ostatniego połączenia oraz historię zmian i usunięć. Treść jest szyfrowana na urządzeniu przed wysłaniem: AES-256-GCM, a klucz sejfu jest zabezpieczony hasłem z użyciem PBKDF2-HMAC-SHA256. Hasło, jawny klucz sejfu i kod ratunkowy nie są wysyłane do usługi.

Przechowywanie zapewnia prywatna baza Cloudflare D1 z ograniczeniem lokalizacji do UE. Sejfy nie są plikami w publicznym repozytorium GitHub. Usługa przypisuje każdy odczyt i zapis do zweryfikowanego konta. Administrator widzi publiczny identyfikator i login, status oraz daty rejestracji, dziennik decyzji, szyfrogramy i metadane techniczne. Te informacje same nie wystarczają do odszyfrowania sejfu. GitHub i Cloudflare mogą przetwarzać adresy IP i dane techniczne zgodnie ze swoimi zasadami; lokalizacja D1 nie oznacza, że całe przetwarzanie sieciowe obu dostawców odbywa się wyłącznie w UE.

3. Dane lokalne i kod ratunkowy

Lokalna kopia, klucz odblokowanego sejfu i sesja są zabezpieczone Windows DPAPI dla danego użytkownika. Nie chroni to przed osobą lub złośliwym programem kontrolującym odblokowaną sesję Windows. Lokalnych ulubionych nie importujemy do konta bez osobnego zaznaczenia. Hasło lub PIN Windows i tożsamość własnego hosta nie są synchronizowane.

Kod ratunkowy odblokowuje ten sam sejf bez zmiany hasła. Nie wysyłamy kodów e-mailem. Zapisz go poza komputerem i traktuj jak klucz: obecnie nie można go unieważnić ani wymienić. Bez hasła, kodu lub nadal odblokowanego urządzenia nie odzyskamy danych. MFDesk nie przeszedł niezależnego audytu bezpieczeństwa.

4. Zdalny pulpit i dostawcy

Obraz monitorów oraz zdarzenia myszy i klawiatury przechodzą bezpośrednio między komputerami szyfrowanym kanałem WebRTC, nie przez bazę kont. Domyślna usługa ntfy.sh przekazuje zaszyfrowane komunikaty zestawienia połączenia; STUN pomaga ustalić adresy sieciowe. Te usługi i drugi komputer mogą poznać adres IP oraz metadane ruchu. Nie ma domyślnego pośrednika TURN, więc nie każda sieć umożliwi połączenie.

GitHub obsługuje logowanie, stronę i pobieranie, Cloudflare — prywatną usługę kont. Nie sprzedajemy tych danych ani nie używamy ich do reklam lub trenowania AI. Więcej: prywatność GitHub i prywatność Cloudflare.

5. Wylogowanie, blokada i usuwanie

  • Usunięcie ulubionego usuwa je z aktywnej listy po synchronizacji, ale zaszyfrowana historia może pozostać w bazie.
  • Wylogowanie MFDesk usuwa lokalną sesję i sejf konta oraz kończy aktywne połączenie zdalne. Nie usuwa chmury, osobnych lokalnych ulubionych ani uprawnień innych urządzeń. Niewysłane zmiany wymagają wcześniejszej synchronizacji.
  • Zgodę GitHub można cofnąć w ustawieniach aplikacji GitHub. Blokada konta przez administratora zatrzymuje kolejne operacje synchronizacji. Żadne z tych działań nie usuwa wcześniej pobranych danych.
  • Trwałe usunięcie konta i sejfu wymaga kontaktu z właścicielem MFDesk. Nie ma jeszcze samoobsługowego przycisku. Dane i rejestr decyzji pozostają do uzgodnionego usunięcia; kopie techniczne dostawcy mogą podlegać jego zasadom retencji.

Aby odebrać dostęp do konkretnego komputera osobie znającej jego klucz, zmień klucz na tym komputerze. Wylogowanie lub blokada synchronizacji nie unieważniają skopiowanych kluczy.

6. Starsze wydania Google i migracja

Wydania 2.2 używały tożsamości Google (identyfikator i e-mail) oraz ukrytej przestrzeni aplikacji na Drive właściciela. Wersja 2.3 może na wyraźne polecenie przenieść odblokowany lokalny sejf na zweryfikowane konto GitHub, odczytując starą usługę, jeśli nadal jest dostępna. Migracja zachowuje hasło, kod ratunkowy i historię. Stary identyfikator Google pozostaje techniczną etykietą szyfrowania; nie jest uprawnieniem do Google ani selektorem dostępu do innego konta.

Migracja nie usuwa automatycznie dawnych kopii Drive, danych Apps Script ani lokalnego profilu Google i nie cofa zgód. Ich usunięcie lub odłączenie wymaga osobnego działania właściciela. Po wyłączeniu starej usługi synchronizacja wydania 2.2 przestanie działać; należy zaktualizować aplikację. Nowa synchronizacja 2.3 nie wymaga Google.

7. Ta strona i kontakt

GitHub Pages udostępnia stronę, a GitHub Releases pojedynczy instalator. Pobieranie nie wymaga logowania. Nie publikujemy sejfów, danych użytkowników, kluczy ani tokenów; nie dodajemy reklam i analityki marketingowej. Dostawca hostingu przetwarza dane żądań potrzebne do dostarczenia i ochrony strony.

Humorystyczna animacja logo używa wyłącznie licznika kliknięć i czasu w pamięci bieżącej karty (sessionStorage). Licznik nie identyfikuje użytkownika, nie jest wysyłany na serwer i jest ignorowany po 2,2 sekundy. Po aktywacji odnośnik „Postaw browarka” prowadzi do zewnętrznej strony wsparcia, która stosuje własne zasady prywatności. MFDesk nie obsługuje płatności ani nie zbiera danych finansowych.

W sprawach konta lub usunięcia danych skontaktuj się z właścicielem MFDesk, od którego otrzymano dostęp do usługi. Zmiany zasad będą oznaczane datą na tej stronie.
